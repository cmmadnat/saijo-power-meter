# Story 3.3: API for EMC Suggestions

## Status
Approved

## Story
**As a** developer,
**I want** to implement the `getSuggestion` API endpoint for the EMC module,
**so that** the system can provide suggestions based on the EMC test results.

## Acceptance Criteria
1. The endpoint `POST /api/v1/emc/suggestion` is implemented.
2. The endpoint correctly handles the request and response formats as defined in `docs/api-schema.md`.
3. The suggestion logic is implemented (the details of the suggestion logic will need to be defined).
4. The data is correctly stored and retrieved from the Firestore database.

## Tasks / Subtasks
- [x] Task 1 (AC: #1, #2, #4)
  - [x] Create `EMCResource.java`.
  - [x] Implement the `POST /api/v1/emc/suggestion` endpoint.
  - [x] Create `EMCService.java`.
- [x] Task 2 (AC: #3)
  - [x] Develop a system prompt for the LLM. The prompt should instruct the LLM to act as an expert EMC engineer and provide suggestions based on the provided test data.
  - [x] Implement a method in `EMCService.java` to format the `EMCDetails` and `EMCTestResult` data as input for the prompt.
  - [x] Implement a client to call the LLM API and return the generated suggestion.

## Dev Notes
- The suggestion logic will be powered by an LLM. The core task is to engineer a high-quality prompt that takes the test data as context and asks the LLM to provide an expert recommendation.

### Testing
- Integration tests should be written for the endpoint. The suggestion logic will require its own unit tests.
