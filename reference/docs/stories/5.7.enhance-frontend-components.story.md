## Reference Frontend Analysis

**Key Pages and Components Identified:**

### Pages:
1. **Dashboard** (`ref-frontend/frontend/src/pages/Dashboard.tsx`)
   - Real-time power consumption monitoring with auto-refresh (60s interval)
   - Manual refresh button with loading states
   - Real-time analytics section with charts (RealTimeKWChart, DailyKWHChart)
   - Individual meter status grid using PowerMeterCard components
   - Error handling and empty states
   - Responsive grid layout (mobile: 1 col, tablet: 2-3 cols, desktop: 4 cols)

2. **UnitDetailView** (`ref-frontend/frontend/src/pages/UnitDetailView.tsx`)
   - Comprehensive meter analysis with tabbed interface (Comprehensive Analysis, Historical Data)
   - Period selector (1h, 24h, 7d, 30d) for analysis timeframes
   - Multiple specialized display components (UptimeTracker, PowerQualityDisplay, PhaseMetricsDisplay, EnergyEfficiencyDisplay)
   - Historical data with DateRangePicker and CSV export functionality
   - Data summary statistics (total points, date range, latest reading)

### Components:
1. **PowerMeterCard** (`ref-frontend/frontend/src/components/PowerMeterCard.tsx`)
   - Displays meter ID with on/off status badge and icon
   - Total power consumption in kW with color coding
   - Phase-wise power breakdown (P1, P2, P3)
   - Estimated daily energy consumption (kWh)
   - Estimated daily cost calculation (when electricity rate available)
   - Last update timestamp
   - Clickable navigation to meter details

2. **RealTimeKWChart** (`ref-frontend/frontend/src/components/RealTimeKWChart.tsx`)
   - Real-time line chart for 3-phase power consumption (24h data, 5m intervals)
   - Auto-refresh with configurable intervals
   - Manual refresh button
   - Custom tooltip showing total and phase power details
   - Legend for total and individual phases
   - Time range and data points information display
   - Loading states, error handling, and empty states

3. **DailyKWHChart** (referenced but not read - similar chart functionality)
   - Daily energy consumption visualization

4. **UptimeTracker** (`ref-frontend/frontend/src/components/UptimeTracker.tsx`)
   - Current session uptime tracking
   - Daily runtime metrics
   - Online/offline status monitoring
   - Last seen timestamp

5. **PhaseMetricsDisplay** (`ref-frontend/frontend/src/components/PhaseMetricsDisplay.tsx`)
   - Voltage, power, and amperage metrics for each phase
   - Current, average, min/max values
   - Threshold status indicators (green/yellow/red)
   - Performance summary across time periods

6. **PowerQualityDisplay** (`ref-frontend/frontend/src/components/PowerQualityDisplay.tsx`)
   - Power factor analysis with trend indicators
   - Phase balance percentage and max deviation
   - Total harmonics distortion
   - Threshold-based status coloring

7. **EnergyEfficiencyDisplay** (`ref-frontend/frontend/src/components/EnergyEfficiencyDisplay.tsx`)
   - Daily, weekly, monthly consumption tracking
   - Peak usage analysis (daily/weekly/monthly peaks with timestamps)
   - Pattern analysis (off-peak/peak hours)
   - Average hourly consumption patterns

8. **DateRangePicker** (`ref-frontend/frontend/src/components/DateRangePicker.tsx`)
   - Date range selection for historical data
   - Loading state integration
   - Validation and error handling

9. **LineChart** (`ref-frontend/frontend/src/components/LineChart.tsx`)
   - Historical power consumption visualization
   - Configurable height and titles
   - Error state handling

- **ElectricityRate**: Rate configuration for cost calculations
- **Meter**: Meter metadata (id, name, department, location, installation date)
- **Department**: Department information for organization
