## Technical Notes

### Integration Approach

**Folder Rename Strategy:**
- Use `git mv` to preserve commit history
- Single atomic commit for rename to avoid confusion
- Update all configuration in the same commit as rename

**Build Process Updates:**
- Maven pom.xml: Change `<directory>lovable-project-7aec971c/dist</directory>` to `<directory>frontend/dist</directory>`
- deploy.sh: Update `cd lovable-project-7aec971c` to `cd frontend`
- Preserve all other build logic unchanged

**Testing Updates:**
- Cypress config file paths
- Any hardcoded paths in test files
- Test documentation and README

### Existing Pattern Reference

Current structure:
```
saijo-backend/
├── admin-ui/              # TO BE REMOVED
├── lovable-project-7aec971c/  # TO BE RENAMED
└── smart-factory-backend/
```

Target structure:
```
saijo-backend/
├── frontend/              # Clean, standard name
└── smart-factory-backend/
```

### Key Constraints

- Must use `git mv` to preserve history, not manual rename
- All changes should be in a single focused commit for clarity
- Build process must work identically before and after rename
- Zero downtime or functionality regression
- All tests must pass with new structure
